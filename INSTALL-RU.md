# Gothic II Co-op: общий опыт и диалоги — бета

Для Gothic II Ночь Ворона 2.6 fix (проверена Steam-сборка 10042765), Union 1.0m. Нужна своя установленная игра у каждого игрока. Архивы не содержат Gothic2.exe, игровые миры или чужие сохранения. Основа: Gothic-Workshop/GothicCoop 60, лицензия AGPL-3.0-or-later.

## Что проверено

Два настоящих процесса Gothic II через локальный ENet: общий опыт, одинаковые повторные законные награды, защита от повторных пакетов, штатное повышение уровня и очки обучения; видимая модель друга и возвращение с бронёй после удаления на расстоянии; запрет второго одновременного диалога; закрытие разговора при истечении разрешения хоста; передача квестовых флагов, журнала и сведений о завершённых разговорах. Отдельно бот вызвал настоящий скрипт принятия задания Лобарта и проверил его состояние у хоста. Все точные результаты находятся в party-test.json.

Сохранения остаются у хоста. Файл COOPGAME.SAV внутри снимка хранит идентификаторы наград и список общих переменных. Только хост сохраняет прохождение. Не сохраняйтесь во время диалога: завершите его, сохраните и дождитесь Host saves: complete. Полная инструкция по сохранениям: README-HostSaves.md.

## Какой архив нужен

- Новая установка: Gothic2Coop-Steam.zip — единый комплект Union, мода, SteamLink и сохранений у хоста. Отдельные старые обновления после него не нужны.
- Уже стоит версия HostSaves: Gothic2Coop-GameplayBeta.zip — обновляет DLL, исходники и инструкцию. Запустите Update.cmd. Если нет Steam-Host-Saves.cmd, используйте полный комплект с новой папкой назначения.

## Установка с нуля — на обоих компьютерах

1. Закройте Gothic II и запустите Steam под своим аккаунтом. Игроки должны быть друзьями в Steam и находиться онлайн.
2. Распакуйте Gothic2Coop-Steam.zip в папку установщика, например C:\G2CoopSetup. Не переносите файлы вручную в основную Steam-игру.
3. Запустите Install.cmd. Исходная игра по умолчанию: C:\Program Files (x86)\Steam\steamapps\common\Gothic II. Отдельная копия создаётся в C:\Games\Gothic2Coop. Папка назначения должна быть новой; существующая установка не перезаписывается. Исходные сохранения не копируются.
4. Для других путей откройте PowerShell в папке установщика:

```powershell
.\Install.cmd -Source "D:\SteamLibrary\steamapps\common\Gothic II" -Destination "D:\Games\Gothic2Coop"
```

5. Путь игровой копии должен целиком состоять из латинских символов: папки «Документы» и «Игра» в пути не подходят Union.
6. При первом запуске Union может сообщить об изменениях DEP/масштабирования и попросить перезапуск игры. Закройте игру и откройте её снова; если Union рекомендует перезагрузку ПК, выполните её перед повторной проверкой.

## Обновление существующей версии HostSaves

1. Закройте игру на обоих ПК. Распакуйте Gothic2Coop-GameplayBeta.zip и запустите Update.cmd.
2. Для другой папки: Update.cmd -Game "D:\Games\Gothic2Coop".
3. Обновление сохраняет старую DLL в .backup-before-gameplay, не заменяет настройки и слоты. Два игрока должны установить один и тот же архив.
4. Инструкция установленной копии: README-Gameplay.md. Возврат старой DLL возможен из резервной папки при закрытой игре; откат версии согласуйте на обоих ПК.

## Первый совместный запуск

1. Хост запускает Steam-Host-Saves.cmd из созданной игровой копии, загружает слот или начинает новую игру. Заканчивает вступительный диалог и нажимает F1 в мире. В игровом журнале должно появиться (Server) Ready.
2. Друг запускает Steam-Join-Saves.cmd из своей копии, загружает мир и заканчивает вступление. Оба должны находиться в одном мире.
3. Друг нажимает Shift+Tab → Друзья → хост → «Подключиться к игре» / Join Game. Закрывает оверлей и ждёт подключения. В этом режиме F2 не требуется.
4. Если у хоста есть снимок этого Steam-аккаунта для загруженного слота, он передаётся и восстанавливается до соединения. При первом входе используется текущий персонаж друга.
5. Оба оставляют окно лаунчера открытым. Используется тестовый Steam AppID 480; Steam может показывать Spacewar. При закрытом лаунчере сначала запустите Steam-Join-Saves.cmd, затем повторите подключение.
6. Shift+Tab открывает оверлей, F10 — окно приглашения в текущее лобби, Shift+F10 — список друзей. Само открытие окна приглашения ничего не отправляет.

## Диалоги, опыт и квесты

- Разговаривать с NPC одновременно может только один игрок, даже если NPC разные. Второй ждёт завершения разговора. При потере связи разговор может автоматически закрыться.
- Новые поддерживаемые награды опыта передаются обоим игрокам. Повторный сетевой пакет не должен начислять награду снова. Старый накопленный опыт при первом подключении не выравнивается.
- Общие флаги и журнал не означают полную синхронизацию всех последствий задания. Предметы и изменения мира перечислены в ограничениях ниже.

## Как сохраняться и продолжать игру

1. Сохраняет только хост. Друг остаётся подключённым и заканчивает диалог. На время записи оба прекращают игровые действия.
2. Хост сохраняет через обычное меню и дожидается Host saves: complete в игровом журнале/лаунчере. До этого не закрывайте игру или лаунчер.
3. После полного окончания первого диалога с Ксардасом создаётся стартовый слот: ищется свободное место от 20-го к 1-му, занятые слоты не заменяются. Если свободных нет, сохранитесь вручную. Прогресс нового друга попадёт к хосту после первого полного сохранения с этим другом.
4. В следующий раз хост загружает тот же слот до F1. Друг входит через тот же Steam-аккаунт; его профиль восстанавливается автоматически.
5. Для загрузки другого слота завершите сеанс и запустите его снова. Загрузка поверх действующего соединения запрещена. Обычное сохранение у друга отключено.
6. Храните резервные копии Saves и CoopHostSaves вместе: одного обычного слота недостаточно для восстановления всех друзей. Не удаляйте CoopHostSaves.

Путь данных: Saves — слоты; CoopHostSaves/generation-*/players/<SteamID> — снимки друзей; CoopHostSaves/slot-N.json — индекс. Логи: system/HostSave.log, system/HostCampaign.log, system/SharedGameplay.log, system/GothicCoopSteamOverlay.log. Подробности — README-HostSaves.md.

## Если не подключается

- Steam API code 2 / Cannot create IPC pipe: откройте Steam, войдите в аккаунт и перезапустите лаунчер. Проверка из SteamLink: G2Steam.exe check --no-launch.
- Union Fatal о символах пути: установите игровую копию в путь с латиницей.
- Есть сеть, но нет персонажа: проверьте одинаковую версию у обоих, один мир, завершённые диалоги и F1 у хоста. Не нажимайте F2 для подключения через оверлей. F3 переинициализирует персонажей; при сохраняющейся ошибке перезапустите сеанс.
- Оверлей не открывается: проверьте его включение в настройках Steam и запуск через файлы Steam-*-Saves.cmd. Прямой Gothic2.exe не включает интеграцию лаунчера.
- Host saves: incomplete / blocked / error: не считайте контрольную точку готовой. Сохраните логи и резервную копию обеих папок данных. Не подменяйте файлы слота вручную.

## Ограничения

Это ещё не полное общее прохождение. Квестовые предметы, создание NPC, их распорядок, отношения, телепорты и срабатывание объектов мира не покрыты общей системой полностью. Не считайте успешную передачу журнала гарантией работы любого задания. Выдача предметов и другие локальные последствия диалога не воспроизводятся автоматически второму игроку.

Не проверены два разных настоящих Steam-аккаунта для этой сборки, переходы между мирами, несколько друзей, вся кампания и откат наград через старый слот. Позднее подключение не начисляет весь опыт за прошлую игру; личный прогресс берётся из сохранённого профиля. Смерть одного и того же мирового NPC награждается один раз в рамках сохранённого прохождения; воскрешение не сбрасывает этот признак.

Перед большим прохождением храните резервные копии Saves и CoopHostSaves вместе. Подробные открытые вопросы: BUGS.md. Автоматические проверки выполнялись в отдельных установках; оригинальная Steam-папка и EXE на диске не изменялись.

Исходники изменённого модуля: Sources-Gameplay.zip. Steam relay остаётся из установленного расширения HostSaves. Исходный проект: https://github.com/Gothic-Workshop/GothicCoop .
