# Gothic II Co-op — установка и игра вдвоём

## Что нужно обоим игрокам

- Своя установленная **Gothic II: Ночь Ворона 2.6 fix**. Проверена Steam-сборка 10042765. Игра в мод не входит.
- Steam: каждый входит в свой аккаунт, добавляет второго в друзья и включает оверлей.
- Одинаковый **Gothic2Coop-Mod.zip** у обоих. Настройки уже внутри, отдельный архив не нужен.

**Это экспериментальная сборка.** Установщик, пароль и передача сохранений прошли отдельные проверки. Последний полный игровой тест остановился при запуске хоста. Работа всей кампании и соединение двух настоящих Steam-аккаунтов пока не подтверждены.

## 1. Установка — сделать каждому

1. Закройте Gothic II и окно старого кооп-лаунчера. Steam оставьте открытым.
2. Распакуйте **весь** Gothic2Coop-Mod.zip, например в `C:\G2CoopSetup`. Не запускайте файлы прямо из ZIP.
3. Запустите **Install-Mod.cmd** из распакованной папки.
4. Выберите **папку установленной игры**, внутри которой есть `system`. Например: `C:\Program Files (x86)\Steam\steamapps\common\Gothic II`.
5. Дождитесь сообщения **Installed Gothic II Co-op**.

Установщик добавляет мод в выбранную игру. Новую копию игры он не создаёт. Union уже входит в комплект. Если Union при первом запуске попросит перезапустить игру или ПК, выполните это перед подключением.

При ошибке «Отказано в доступе» запустите Install-Mod.cmd правой кнопкой → **Запуск от имени администратора**.

Путь к игре должен быть **без русских букв**. Если в нём есть кириллица, сначала перенесите игру средствами Steam в библиотеку с латинским путём.

## 2. Настройки — сделать каждому

В **папке игры**, а не установщика, откройте **CoopSettings.ini** через Блокнот.

У хоста, например:

```ini
[Coop]
PlayerName=Vasya
ServerPassword=MyCoop123
```

У друга:

```ini
[Coop]
PlayerName=Petya
ServerPassword=MyCoop123
```

- **PlayerName** — своё имя, латиница и цифры, до 63 символов.
- **ServerPassword** — одинаковый пароль у обоих, до 127 символов. Пустое значение у хоста (`ServerPassword=`) отключает пароль.
- Пустое имя сохраняет прежнее имя. Оно не меняет SteamID и привязку прогресса.

Нажмите **Ctrl+S**. Файл должен остаться `CoopSettings.ini`, а не `CoopSettings.ini.txt`. Меняйте настройки при закрытых игре и лаунчере; затем запускайте их заново.

Пароль хранится в INI открытым текстом. Не публикуйте этот файл с настоящим паролем.

## 3. Хост создаёт игру

**Хост** — игрок, у которого будут храниться сохранения обоих.

1. В папке игры запустите **Steam-Host-Saves.cmd**.
2. Оставьте окно лаунчера открытым до конца игры.
3. Загрузите сохранение или начните новую игру.
4. Полностью закончите вступительный разговор с Ксардасом.
5. В игровом мире нажмите **F1**. Дождитесь **(Server) Ready**.
6. Теперь друг может подключаться.

## 4. Друг подключается

1. В своей папке игры запустите **Steam-Join-Saves.cmd**.
2. Оставьте окно лаунчера открытым.
3. Загрузите мир или начните новую игру, закончите вступление. Оба игрока должны находиться в одном мире.
4. Нажмите **Shift+Tab → Друзья → хост → Подключиться к игре / Join Game**.
5. Закройте оверлей и дождитесь соединения. **F2 не требуется.**

При повторном входе снимок этого Steam-аккаунта восстанавливается от хоста до подключения. При первом входе используется текущий персонаж друга.

**Запускайте именно CMD.** Обычная кнопка «Играть» в Steam или запуск Gothic2.exe напрямую не включают наш сетевой лаунчер. Steam может показывать **Spacewar**: используется тестовый AppID 480.

## 5. Сохранить и продолжить позже

1. Завершите разговоры с NPC. Оба временно прекратите действия.
2. **Хост** сохраняет через обычное меню игры.
3. Дождитесь **Host saves: complete**. До этого не закрывайте игру или лаунчер.
4. Друг вручную не сохраняется: его снимок отправляется хосту.

При следующем запуске хост загружает **тот же слот** и нажимает F1. Друг подключается через **тот же Steam-аккаунт**.

Чтобы загрузить другой слот, сначала завершите сетевой сеанс и запустите его заново. Для резервной копии храните **Saves и CoopHostSaves вместе**. Одного обычного слота недостаточно для восстановления друзей.

После завершения первого диалога с Ксардасом предусмотрено стартовое автосохранение в свободный слот. Если свободных нет, сохранитесь вручную. Прогресс нового друга попадёт к хосту после первого полного сохранения с ним.

## Если не работает

| Проблема | Что сделать |
|---|---|
| Gothic2.exe not found | Выберите установленную игру с `system\Gothic2.exe`. Одного архива мода недостаточно. |
| Неподдерживаемая версия | Нужна Ночь Ворона 2.6 fix, проверенная Steam-сборка 10042765. |
| Отказано в доступе | Запустите установщик от имени администратора. |
| Incorrect server password / Password required | Сверьте ServerPassword у обоих, сохраните файл и перезапустите CMD. |
| Ошибка Steam API | Войдите в Steam и заново запустите CMD. |
| Нет оверлея | Включите его в Steam, запускайте игру через CMD из этого мода. |
| Нет «Подключиться к игре» | Хост должен запустить свой CMD, загрузить мир и нажать F1. Оба должны быть онлайн и в друзьях. |
| Друг не виден | Сверьте сборку, мир, завершение вступления и F1 у хоста. Перезапустите сеанс. |
| Камера диалога есть, ответов нет | Завершите сеанс, проверьте одинаковую сборку и начните с полной контрольной точки. Сохраните логи. |
| Host saves: incomplete / blocked / error | Сохранение не считается готовым. Не удаляйте CoopHostSaves и не подменяйте слоты вручную. Сохраните логи и обе папки данных. |

Для разбора ошибки нужны текст из окна лаунчера и созданные логи из `system`: **HostCampaign.log**, **HostSave.log**, **SharedGameplay.log**. Пароль и личные сохранения публично выкладывать не нужно.

## Удалить или обновить

Закройте игру и лаунчер. В распакованном установщике запустите **Uninstall-Mod.cmd**, выберите ту же игру. Для обновления затем установите новый полный архив на обоих ПК.

Сохранения и **CoopSettings.ini останутся**. Заменённые файлы восстанавливаются из `.gothic2-coop-mod/backup`: не удаляйте её заранее. Если файл изменён другим модом, удаление остановится, чтобы не затереть изменение. Если до установки уже был старый кооп, он вернётся после удаления нового.

## Ограничения

Мод активен во всей выбранной установке как плагин Union. Это не запись GothicStarter и не Steam Workshop. Совместимость с другими сюжетными модами не проверена.

С NPC одновременно разговаривает только один игрок. Общие флаги и журнал ещё не обеспечивают полную синхронизацию квестовых предметов, создания NPC, распорядков, отношений, телепортов и изменений мира. Полное прохождение, переходы между мирами и несколько друзей пока не подтверждены.
